# data/decisions/ — inputs set by judgment

Everything here is a decision that the pipeline reads as input. None of it is generated by
the rebuild, and none of it can be regenerated from the images. After any change, run
`scripts/rebuild_all_outputs.sh`.

| File | Decision | Read by |
|---|---|---|
| `qc_excluded_samples.csv` | Sections excluded whole (`action=exclude`) or kept with a caveat (`action=caveat`), with the reason. | `aggregate_cohort.py` and every report |
| `fov_sampling_overrides.csv` | Field-grid geometry for small cores and biopsies: grid pitch, edge erosion, minimum tissue fraction, field size. A blank field size keeps the 500 µm default. | `hpc/run_il15_array.sh`, `hpc/run_dab_threshold_check.sh`, reports |
| `stain_vectors_FINAL.csv`, `.md` | The stain vectors in use, measured on single-stain slides on 2026-08-07. The pipeline carries them as literal constants in `macros/il15_ihc_pipeline.ijm`; this is the record of how they were chosen. | none; reference |
| `field_exclusions/<section>_fov_exclude.csv` | Fields excluded from one section, one row per field (`fov_id,reason`). The reason records which QC round made the call and on what evidence. | `aggregate_cohort.py` and the field-QC pages, through `site_paths.field_exclusion_rows()` |

`field_exclusions/` has one file per section that has any exclusions: 73 of 74 sections.
File names drop the `_EXCLUDED` suffix that excluded sections carry on their
`per_sample_out/` folder, so a section keeps the same file name before and after it is excluded.

The reason text in each field-exclusion row was written when the decision was made. Some
rows cite sections of the internal analysis log, which is not part of this repository.

Until 2026-09-30 these files lived beside the results. The first three were in
`outputs/tables/`, and each field-exclusion file was in its section's `per_sample_out/` folder.
The QC-record scripts in `scripts/qc_record/` still name the old paths.
